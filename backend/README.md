# Backend Skeleton

Этот каталог содержит каркас серверной части на C++ под Crow, чтобы архитектура проекта соответствовала ТЗ.

План интеграции:

1. `src/main.cpp` поднимает HTTP-сервер.
2. Игровые режимы описываются отдельными классами.
3. Клиент обменивается с сервером JSON-запросами:
   - `POST /startGame`
   - `POST /move`
   - `POST /settings`
   - `POST /restart`

Текущая версия фронтенда уже работает автономно в браузере, а этот каркас можно использовать как следующую итерацию для переноса логики на C++.
